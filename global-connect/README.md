# Global Connect

Standalone page project. Same base stack as the Labour CESS deck (React 19, Vite, Tailwind 4, Motion, Phosphor, Radix) with React Router for routes.

```bash
cd global-connect
npm install
npm run dev     # http://localhost:5174/global-connect
```

Add new routes in `src/App.tsx` and pages in `src/pages/`.
